# Operations journal — 2026-09

## 2026-09-06 — OpenClaw Gateway intentionally disabled

- `openclaw-openclaw-gateway-1` is intentionally stopped on `vps-hetzner-prod`.
- The decision follows repeated memory pressure and an operator decision to keep
  the Gateway offline rather than allow automatic restarts.
- `/opt/openclaw/config`, the working data, and Docker resources remain retained
  for an owner-led recovery; this repository must not restart or delete them.
- The host inventory marks the container in `disabled_containers`, so monitoring
  excludes it from expected-container alerts.
- Re-enable only after `openclaw_firststeps` approves a resource and recovery plan.
